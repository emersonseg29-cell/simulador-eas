# simulador-eas

Simulador Oficial EAS Corretora com produtos Unimed e catálogo técnico de Convenções Coletivas Porto.

## Convenções Porto

O arquivo `convencoes.js` concentra os dados dos produtos. Propostas antigas permanecem identificadas como históricas. Produtos sem preço confirmado não realizam cálculo e exibem aviso de atualização necessária.

### Regra operacional vigente

O código Porto `3-431` permanece com CCT/documentação preservada quando sustentada por fonte oficial, mas o preço por vida, prêmio mínimo e faixas estão `PENDENTE_HOMOLOGACAO`. O simulador não deve calcular nem divulgar valores desse código até entrada de simulação oficial Porto.
